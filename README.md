# Currency Converter

A responsive currency converter built with HTML, CSS and JavaScript.
Converts between 150+ currencies using a live exchange rate API.

## Features
- Live exchange rates
- Searchable country dropdown (search by country name or currency code)
- Country flags for every currency
- Responsive design with animated background

## Tech Stack
HTML, CSS, JavaScript, Fetch API
